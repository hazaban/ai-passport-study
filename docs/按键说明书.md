# 考研日程助手 · 按键操作说明书

设备只有 **3 个按键**：`上`、`下`、`OK`（返回键即 OK 的长按）。屏幕 240×320。

---

## 0. 通用约定

| 操作 | 含义 |
|------|------|
| 短按 OK | 确认 / 勾选完成 / 进入选中项 |
| **长按 OK** | **返回上一级**（例如从 Todo 返回封面，从设置返回封面）|
| 短按 上/下 | 在"可选项"之间移动 / 上下滚动 |
| 长按 上/下 | 在 Todo 页里切换 **大页签**：日常任务 ⇄ 学习科目 |

> 大部分页面在**任意位置**长按 OK 都是返回；个别页面 OK 有专门功能。

---

## 1. 封面（首页）

开机即进入。显示：顶部日期、中央**考研倒计时**卡（天数+考试日期）、下方两个按钮。

- `上/下`：在「进入学习」「设置」两个按钮间切换（当前项会**变蓝**，另一个是白卡）
- 短按 `OK`：进入选中项
  - 选中「进入学习」→ 今日 Todo 列表
  - 选中「设置」→ 设置页
- 长按 `OK`：退出考研助手回主目录（封面时无意义，忽略）

---

## 2. 今日 Todo（学习主页）

顶部：标题、倒计时、日期(星期)、进度（已完成/总数）。
页签：**日常任务** / **学习科目**，当前页签高亮。任务行：左端有**方框**（未完成=白框，已完成=绿底打勾 ✓，整行灰字+划线），右侧为时间。

| 按键 | 效果 |
|------|------|
| 短按 `下` | 往下选下一条任务；到末尾再按进入底部栏 |
| 短按 `上` | 往上选上一条任务 |
| **长按 `上` / `下`** | **切换页签**：日常任务 ⇄ 学习科目（并回到该页顶部） |
| 短按 `OK`（在任务上）| **勾选/取消勾选**该任务 = 点击它前面的方框。勾选完成时：变灰+划线、进度+1，并**自动播放**该类别 RTTTL 旋律 + 鼓励语音 + 弹鼓励文案；再按一次取消（不发声）|
| 短按 `OK`（在底部栏）| 「+ 添加任务」→ 添加页；或「设置」→ 设置页 |
| 长按 `OK` | 返回封面 |

> 底部栏到达方式：一直按 `下`，越过最后一条任务即进入底部栏（+添加 / 设置 之间按 `下` 切换、按 `OK` 进入）。

---

## 3. 添加任务

从 Todo 底部「+ 添加任务」进入。当前为**模板式**快速添加（预设常用任务）。

- `上/下`：选择模板（可翻页）
- 短按 `OK`：按所选模板添加一条任务，回到 Todo 列表
- 长按 `OK`：返回 Todo（不添加）

> 预设含各科（高数/线代/概率/数据结构/…/英语/政治）与日常场景（洗漱/吃饭/睡觉/洗头等）。
> 语音输入添加、时间微调：开发中（设计方案 Phase2）。

---

## 4. 设置页

从封面「设置」或 Todo 底部「设置」进入。列表包含亮度、音量、时间、WiFi 等（按实现逐步开放）。

- `上/下`：选择设置项
- 短按 `OK`：进入该项（WiFi → 配网页；亮度等 → 直接调/翻页调）
- 长按 `OK`：返回进入前的页面

---

## 5. WiFi 配网（SoftAP 网页）

- 设备无凭证时开机自动开热点 `STU_STUDY_xxxx`；手机连它，浏览器打开 `http://192.168.4.1/` 填 WiFi 后自动连网校时。
- 设置→WiFi 可进入该页。

---

## 6. 关于"完成语音"

勾选任务完成是**自动播放语音**的，无需额外按键：
1. 先播该科目的 RTTTL 提示旋律（1~2 秒）；
2. 接着播水豚噜噜风格的**鼓励人声**；
3. 屏幕同时显示该类别颜色的鼓励文案弹窗，**短按 OK 关闭**弹窗后继续操作。

取消勾选（再按一次 OK）不播放。

---

## 7. 常见问答

- **为什么看不到字/一团黑？** 早期版本字库格式问题，已在 bpp4 重建版修复；如仍异常请告诉我截图/现象。
- **任务前面的方框按哪个键？** 把光标移到该任务（短按上/下使其高亮），**短按 OK** 即勾选/取消。
- **能不能直接改某任务？** 删除/编辑入口将在后续版本加到任务详情。
- **顶部日期是 1970？** 未联网校时；联网后自动 SNTP 校时（中国时区已内置）。
